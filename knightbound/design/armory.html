How it works

Set and rarity are two things

The set is the shape

Which beast a piece belongs to decides its name, silhouette and colour. Matching pieces count toward that set's bonus; the best set you wear applies, so two and two gives you the better pair.

2 · 3 · 4 pieces×1.08, ×1.16, ×1.25 on the set's stat. Flat, never scaling with the stage.
4 piecesadds the set's trait. The trait is the reason to finish a set rather than wear four better strays.
3 Dragon + 1 WolfDragon 3/4: ×1.16 damage. The stray Wolf boots count for nothing.
2 Wolf + 2 DragonTwo pairs: only one applies. A tie goes to the helm's set, so this is Wolf ×1.08 speed.

Rarity is the gem

How good a piece is shows as a gem (in the helm's brow and the item frame) and, on the helm, how closed it is. The set keeps the shape: a Legendary Wolfhead Hood is still a wolf, just in a mask.

  • Common ×1.0 roll · 1 stat line70% of normal drops
  • Rare ×1.5 roll · 2 stat lines22%
  • Epic ×2.2 roll · 3 stat lines7%
  • Legendary ×3.2 roll · 4 stat lines1%
  • Super Legendary ×4.5 roll · 5 stat linesbosses only, ~1 in 400

For the next set

Adding set eleven

Every set is the same six decisions. Answer these and the new set is ready to draw, name and balance.

BeastOne creature with a silhouette readable at 12 px: horns, ears, a beak, a mane.
CrestThe one helm shape that says the beast. It must not hide the face or collide with the blade.
PaletteA 4-step main ramp and a trim ramp. Helm stays the light band, body mid, blade brightest.
PiecesFour names that read as things: "Dragonfang", not "Epic Sword".
Stat and traitOne stat for the 2–4 piece tiers, and one four-piece trait that changes how a fight plays.
StageWhere it starts dropping. New sets go above the last one, so the list grows with the game.

Before it's built

Open questions

  1. One stat per set, or all three? The earlier plan multiplied damage, HP and coins for every set. This page gives each beast its own stat so sets feel different. Which do you want?
  2. Four-piece traits. Traits like Rebirth and Dragonfire are new mechanics, each with its own code and tests. Keep all ten, trim to a few, or start with the tiers only?
  3. Drop bands. Wolf and Stag from stage 1, Phoenix from stage 60. Should the late sets need an Ascend first?
  4. Names. These names end up saved in players' bags. Change any now, while it's cheap.
